## About This Site

This portfolio is engineered, not just designed:

- ⚡ **Single-file, dependency-light** — plain HTML/CSS/JS, no build step, deploys instantly on GitHub Pages
- 🔍 **SEO-optimized** — semantic HTML, Open Graph + Twitter Card metadata, canonical URLs
- 🤖 **AI-crawler friendly** — `Person` and `FAQPage` JSON-LD structured data, plus an [`llms.txt`](./llms.txt) file so AI assistants (ChatGPT, Claude, Perplexity) can accurately summarize who I am and what I do
- 📱 **Fully responsive** — mobile-first layout, tested across breakpoints
- ♿ **Accessible** — semantic landmarks, reduced-motion support, keyboard-navigable
- 🗺️ **Crawl-ready** — `robots.txt` and `sitemap.xml` included for search engine indexing
